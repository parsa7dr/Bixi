# bixiprogrammingassignment


A Java-based project focused on implementing custom data structures and processing bike trip data using object-oriented programming principles.

## Overview

This project demonstrates the design and implementation of custom data structures while handling and organizing real-world-inspired transportation data. The system follows a modular architecture to improve scalability, maintainability, and code organization.

## Features

- Custom hash table implementation
- Custom linked list implementation
- Custom array list implementation
- Bike trip data processing and management
- Modular MVC-style architecture
- Object-oriented system design

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Custom Data Structures
- MVC Architecture

## Project Structure

The project is organized into multiple components responsible for:
- Data storage and management
- Trip processing logic
- User interaction and control flow
- Custom collection implementations
